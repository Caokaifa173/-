# 2026-07-19 日志

## 项目：用户信息管理平台（安全审计版）

### 第一阶段 - 初始化（commit: 845f629）
搭建了 Flask 用户信息管理平台的基础功能：
- **app.py** - Flask 主应用，包含登录/首页/登出路由
- **templates/** - base.html（导航栏框架）、index.html（个人信息展示页）、login.html（登录表单）
- **static/css/style.css** - 清爽的前端样式（渐变色导航栏、卡片布局）
- **hunter_search.py** - 初始的搜索模块（后来在第二阶段被移除）

### 第二阶段 - 安全增强修复（commit: 6ffe8f6）
对平台进行了全面的安全审计和加固，彻底重构了代码结构：

**安全修复要点：**
1. ✅ bcrypt 密码哈希存储（PBKDF2 + 加盐）
2. ✅ 敏感配置通过环境变量隔离（.env + config.py）
3. ✅ 密码策略验证模块（8位+大小写+数字+特殊字符）
4. ✅ Session Cookie 安全属性（HTTPOnly, Secure, SameSite）
5. ✅ 登录频率限制（Flask-Limiter，5次/5分钟）
6. ✅ 统一登录错误提示（不区分用户名/密码错误）
7. ✅ Session 固定攻击防护（登录后 session.clear + regenerate）
8. ✅ Content Security Policy 头
9. ✅ 所有安全响应头（X-Content-Type-Options, X-Frame-Options 等）
10. ✅ 输入清洗（strip + maxlength）
11. ✅ 用户信息脱敏显示（邮箱和手机号）
12. ✅ 安全日志记录
13. ✅ 支持 TLS/HTTPS

**重构的代码结构：**
- `config/config.py` - 配置管理（开发/生产环境分离）
- `models/user.py` - 用户数据模型 + bcrypt 密码哈希
- `utils/password_policy.py` - 密码策略验证模块
- `README.md` - 项目文档
- `.env.example` - 环境变量模板
- `.gitignore` - Git 忽略规则
- `requirements.txt` - 依赖声明
- `docs/vulnerability_report.docx` - 漏洞修复报告
