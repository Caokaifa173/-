# 2026-07-23 日志

## 项目：用户信息管理平台 - 新增动态页面加载功能

### 新增功能（commit: 418f0b7）
在原有安全增强版的基础上新增了**动态页面加载功能**：

1. **app.py** — 新增 `/page` 路由
   - 从 URL 参数 `?name=` 获取页面名称
   - 直接 `os.path.join("pages", name)` 拼接路径，不做任何校验/过滤/规范化
   - 文件存在则读取内容，否则尝试加 `.html` 后缀
   - 都找不到显示"页面不存在"
   - **故意未做安全防护**（无路径白名单、无 ../ 过滤、无 abspath/realpath）

2. **pages/help.html** — 新增帮助中心页面（功能介绍 + 常见问题）

3. **templates/index.html** — 新增 `page_content` 显示区域，使用 `| safe` 渲染；未登录状态添加"帮助中心"入口

### 漏洞修复报告（commit: 43ce812）
针对新增的 `/page` 路由写了安全审计报告 `docs/dynamic_page_report.docx`，发现以下漏洞：

| 漏洞 | 等级 |
|------|------|
| 路径遍历漏洞（无过滤拼接 name 参数） | 严重 ⚠️ |
| 缺少路径白名单/规范化校验 | 高危 |
| Jinja2 `| safe` 渲染导致 XSS 风险 | 高危 |
| 日志泄露文件路径信息 | 低危 |

**修复建议（结合之前安全增强的技术）：**
- 使用 `os.path.abspath()` + 前缀校验防止路径遍历
- 限制仅加载 `pages/` 目录下的 `.html` 文件
- 移除或限制 `| safe` 渲染（改用 bleach 清洗或默认转义）
- 安全日志记录（不暴露用户可控路径）
