# 2026-07-24 日志

## 项目：用户信息管理平台 - 新增密码修改功能

### 第一次提交（commit: 38b1159）- 新增密码修改功能
在原有功能基础上新增了**密码修改功能**：

1. **app.py** — 新增两个路由：
   - `/profile`：个人中心页面（需要登录，未登录重定向到登录页）
   - `/change-password`（POST）：修改密码功能
     - 从表单接收 username、new_password、repassword
     - 不验证原密码
     - 不验证 CSRF Token
     - 不验证 session 用户和提交的 username 是否一致
     - 两次密码不一致则重定向回 /profile
     - 成功后重定向到 /profile

2. **templates/profile.html**（新建）— 个人中心页面
   - 展示用户信息（用户名、角色、邮箱、手机、余额）
   - 包含修改密码表单（新密码、确认密码、修改按钮）
   - 通过隐藏字段传递 username

3. **templates/index.html** — 已登录状态增加「个人中心」入口按钮

4. **models/user.py** — 新增 `update_password()` 方法
   - 用 bcrypt 哈希新密码后直接更新
   - 用户不存在返回 False

### 第二次提交（commit: 7fc6809）- 密码修改功能漏洞修复报告
生成 `docs/day7漏洞修复报告.docx`，发现 5 个漏洞：

| # | 漏洞名称 | 等级 |
|---|---------|------|
| 1 | 任意用户密码修改（越权） | 🔴 严重 |
| 2 | 无需验证原密码 | 🔴 高危 |
| 3 | 无 CSRF Token 防护 | 🔴 高危 |
| 4 | 敏感字段暴露在前端 | 🟡 中危 |
| 5 | 无请求来源校验 | 🟡 中危 |

### 安全隐患
- 任何已登录用户可修改任何人的密码（包括 admin）
- 通过隐藏字段修改 username 即可修改其他人的密码
- 无需原密码验证
- 无 CSRF Token 防护
- 可结合 CSRF 攻击实施完整的账号接管链
